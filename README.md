# License Pricing Curve Tool

Interactive volume-based license pricing negotiation tool. Created by Peter Grant-Hay.

## Usage

Open `license-pricing-calc.html` in any modern browser — no server or build step required.

### Features

- **Product Pricing Tiers** — define volume bands and per-unit prices
- **Product Variants** — manage multiple product configurations side by side
- **Customer Business Case Scenarios** — model multi-year volume projections
- **Pricing Curve** — interactive drag-to-adjust chart with lock controls and undo
- **Negotiated Pricing** — editable tier table with revenue comparison
- **Export** — CSV export with cumulative or yearly volume distribution
- **Session Save/Load** — persist all data in browser storage across sessions
- **Dark Mode** — toggle for low-light environments

### Session Management

- **Save Session** — saves all variants, tiers, business cases, negotiated pricing, and settings to browser local storage
- **Load Session** — restores a previously saved session
- **Reset All** — returns everything to factory defaults
